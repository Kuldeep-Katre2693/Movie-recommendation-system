# CineAI – Smart Movie Discovery Web App

CineAI is a modern movie discovery web application powered by the OMDb API. It allows users to search movies, explore genres, view detailed movie information, receive recommendations, and maintain a personalized watchlist—all from a clean and responsive interface.

## Features

### Live Movie Search

* Search movies, actors, or directors in real time
* Fetch accurate IMDb data instantly
* View posters, ratings, release year, and movie details

### Genre-Based Exploration

* Browse curated movies across 12 popular genres
* Includes Action, Adventure, Comedy, Horror, Sci-Fi, Animation, Romance, Thriller, and more

### Detailed Movie Information

* Complete plot summary
* Cast and crew information
* Director and writer details
* IMDb, Rotten Tomatoes, and Metacritic ratings
* Awards and box office information

### Smart Recommendations

* Discover similar movies based on your selected title
* Personalized movie exploration experience

### Personal Watchlist

* Save favorite movies with a single click
* Persistent storage using browser localStorage
* Access saved movies from a slide-out sidebar

### IMDb Integration

* Direct link to the official IMDb page of every movie

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* OMDb API
* Local Storage

## Getting Started

1. Obtain a free API key from OMDb.
2. Open `cineai.html` in your browser.
3. Enter your API key and connect.
4. Start exploring movies and building your watchlist.
